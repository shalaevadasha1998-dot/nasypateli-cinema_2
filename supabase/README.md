# Supabase

Рабочий проект: `vwteokawtqnoiyzmsldj`.

Единственная публикуемая серверная функция — `functions/app`.
Её выпуск выполняет GitHub Actions из `.github/workflows/supabase-functions.yml`.

Актуальные изменения рабочей базы хранятся только в `migrations/*.sql`. Префикс каждого файла совпадает с версией в production migration history, поэтому новые миграции нельзя переименовывать или применять в обход этого журнала.

Корневые `schema.sql`, `seed.sql`, `SETUP_THIS_PROJECT.sql` и `PATCH_*.sql` сохранены только как история существующей базы и ручного начального развёртывания. Они не запускаются при выпуске и не должны применяться вслепую к рабочей базе.

Перед статусом готовности рабочая функция проверяет:
- обязательные таблицы;
- конфигурацию пилота 3 октября;
- реальный Telegram-бот и его webhook;
- оплату;
- OpenAI;
- административный доступ;
- экран и служебную задачу;
- отсутствие демонстрационной авторизации.
