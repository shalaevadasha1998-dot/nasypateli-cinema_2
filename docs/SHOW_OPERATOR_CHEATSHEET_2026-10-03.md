# show operator cheat sheet — 3 октября 2026

короткая версия для человека у ноутбука.

## до открытия дверей

1. открыть admin события.
2. нажать «проверить вечер».
3. если есть красный block — не запускать шоу, сначала исправить его.
4. warning про финальный art pack не блокирует вечер: rabbit fallback уже работает.
5. warning про внутренний зал закрывается физической проверкой площадки.
6. нажать «получить ссылку экрана».
7. открыть projector link на ноутбуке проектора.
8. включить fullscreen.
9. нажать «репетиция животин ↗».
10. проверить картинку, имена, анимацию входа.
11. вернуться в admin.
12. получить ссылку чек-ина.

## когда открылись двери

- экран должен оставаться на блоке «сбор гостей».
- гость проходит telegram check-in.
- animal появляется автоматически.
- если animal не появилась: открыть «список участников» → найти человека → «отметить пришёл».
- не добавлять demo-животин в production.

## старт

нажать «начать мероприятие».

после этого show runtime сам перейдёт в running и начнёт первый блок программы.

## переходы программы

обычный переход:
- «следующий блок →»

если нужно:
- «← назад»
- «пауза»
- «продолжить шоу»
- «перезапустить блок»
- «пропустить блок»

music live:
- «начать music live»
- после выступления «закончить выступление»

кнопку «закончить мероприятие» использовать только в самом конце.

## кинораунд старого общего пульта

если используется обычный round-control:
1. «запустить раунд».
2. «запустить рандом» фильма или «выбрать вручную».
3. при необходимости сохранить вопрос аудитории.
4. «открыть голосование».
5. «закрыть голосование».
6. «показать результаты».
7. «запустить видео» / «остановить видео».
8. «закрыть раунд».

## новый film mechanic

для подготовленного film package:

1. «показать первый фрагмент».
2. «собирать одно слово».
3. «зафиксировать стену слов».

дальше для каждого вопроса 1–5 строго:
1. «открыть вопрос».
2. дать людям ответить в телефоне.
3. «результаты».
4. «правильное + фрагмент».

после вопроса 5:
1. «запустить рандом на экране».
2. «выбрать животинку».

важно:
- server assignment делается один раз;
- повторное нажатие не должно выбирать нового победителя;
- eligibility: attended + одно слово + все 5 ответов;
- победитель получает film mission на 7 дней.

## если видео не играет

1. остановить видео.
2. в каталоге источников открыть текущий source.
3. если он умер → «источник умер».
4. если источник нельзя использовать → «заблокировать».
5. resolver выберет следующий ready source.
6. при необходимости выбрать проверенный source вручную через «выбрать этот».
7. для film package проверить sourcePlatform + start/end.

## если projector выглядит неправильно

- обновить projector page.
- проверить, что открыта именно screen link из текущей admin.
- проверить fullscreen.
- открыть «репетиция животин ↗».
- если demo работает, а live нет — проверить check-in/attended.
- если demo тоже не работает — проверить browser/network/projector input.

## конец вечера

1. закончить последний активный блок.
2. проверить, что assignment победителя уже создан.
3. перейти в finale.
4. только затем нажать «закончить мероприятие».
5. после закрытия не делать повторный check-in и не перезапускать show runtime без причины.

## что нельзя импровизировать

- не менять production data ради визуальной репетиции.
- не выбирать source с blocked rights.
- не выдавать человеческие имена на projector.
- не менять программу/тайминги в последний момент без причины.
- не нажимать «закончить мероприятие» для обычной паузы.
