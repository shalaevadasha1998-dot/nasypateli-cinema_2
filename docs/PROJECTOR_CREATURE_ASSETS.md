## минимальный финальный набор, который нужно нарисовать

### пять стадий животины

1. projector-stage-0.webp
2. projector-stage-1.webp
3. projector-stage-2.webp
4. projector-stage-3.webp
5. projector-stage-4.webp

для всех пяти:
- прозрачный фон;
- одинаковый canvas;
- одинаковая линия пола;
- тело полностью помещается в safe area;
- читаемый силуэт на расстоянии;
- без мелкого текста;
- без человеческого имени внутри картинки;
- одинаковое направление света;
- заметное взросление/изменение формы от stage 0 к stage 4.

рабочая спецификация для художника:
- canvas: 1024×1024 px;
- прозрачный webp или png;
- персонаж занимает примерно 75–82% высоты;
- нижняя точка персонажа находится на одной baseline;
- важные детали не ближе 80 px к краям;
- файл должен хорошо выглядеть после уменьшения примерно до 80×80 px на стене из 50 животных.

1024×1024 — рабочая рекомендация проекта, а не требование площадки.

### четыре event pose

6. projector-enter.webp
7. projector-think.webp
8. projector-winner.webp
9. projector-review.webp

назначение:
- enter — короткий геройский вход после check-in;
- think — состояние вопроса/ожидания;
- winner — animal, которому достался фильм;
- review — карточка после 7-дневной миссии.

для первого мероприятия эти позы не являются блокером: entrance уже делается css-анимацией, winner/review имеют fallback art.

## что не надо рисовать

не нужны отдельные картинки на каждого гостя.
не нужны 50 уникальных животных.
не нужно рисовать человеческие аватары.
не нужно вписывать animal name в png/webp: имя рисуется html-текстом, поэтому остаётся резким на любом projector.

## принцип кастомизации

у гостя одна серверная animal identity.
визуально она определяется стадией и позже может дополняться cosmetics.
projector должен получать только public animal state, а не human profile.

если появятся аксессуары/cosmetics, лучше рисовать их отдельными прозрачными слоями:
- body;
- head accessory;
- face;
- neck/body accessory;
- special effect.

так один набор картинок можно комбинировать, а не экспортировать сотни готовых персонажей.

## анимация

для 3 октября безопаснее использовать:
- статичные прозрачные sprites;
- движение делать css;
- animated webp использовать только если он заранее прогнан на реальном ноутбуке/projector.

это уменьшает риск лагов при стене из 30–50 животных.

## критерий готовности арт-пака

готово, когда:
- 5 stage sprites экспортированы;
- каждый имеет прозрачность;
- baseline совпадает;
- нет обрезанных ушей/лап/эффектов;
- все 5 одновременно читаются в 1920×1080 projector preview;
- 50 карточек не вызывают заметного торможения;
- имена остаются html, не baked into artwork;
- права на все исходники принадлежат проекту или подтверждены.
